# DiPlay Geely E01 — v0.4.8-geely

星瑞 E01 车机的 CarPlay 接收端。对应车机是 ECARX E01 / MediaTek MT6735 / GKUI 19，
系统 **Android 5.1（API 22）**。versionCode **48**，包名 `com.shihab.diplay`。

底子还是 `programmerguohuajing/DiPlay-Legacy-Android` **v0.2.7**。
签名与上一版完全一致，**直接覆盖安装即可**，之前保存的分辨率、音频缓冲、方向盘按键和 Wi-Fi 凭证均完整保留。

这一版的核心优化：**根治 0.4.7 热点与 Wi-Fi 无法自动启闭、双模切换广播假死、页面状态显示延迟/图标闪烁、以及 U 盘日志落盘受限问题**。

---

## 一、功能优化与修复说明

针对 0.4.7 版本在实车环境下的测试反馈，进行了全链路排查与体验优化：

1. **车载热点与 Wi-Fi 自动启闭彻底根治（解决 0.4.7 无法自动开关热点/Wi-Fi）**：
   - 彻底淘汰旧版高延迟后台调用，升级为车机原生静默通道直接调度，毫秒级快速响应；
   - 严格以车机无线芯片的真实硬件工作状态为准，彻底杜绝状态误判与硬件冲突；
   - 修复首次进入应用时主界面对热点就绪状态的显示延迟，热点就绪时即刻刷新，不再误显“热点未准备好”；
   - 优化连接等待界面的视觉呈现，移除导致视觉闪烁的透明度跳变动画，保持 CarPlay 图标稳定常亮。

2. **双模切换链路彻底自愈（热点模式 ⇄ 同网模式）**：
   - 修复切换无线模式时旧连接会话未完全退出导致无线射频被跳过对齐的问题，切换时即时收尾旧会话，射频即刻重新对齐；
   - 优化同网模式下的网络寻址与广播握手，双向切换模式均可秒级发现 iPhone。

3. **外置 U 盘诊断日志真实落盘与即拔即存**：
   - 准确识别并穿透写入真实插入的物理 U 盘，杜绝“显示存入实则落在车机内部”的现象；
   - 写入 U 盘后强制执行硬件级物理刷盘（Sync），拔出 U 盘插上电脑即可在根目录直接看到 `DiPlay` 文件夹及排障报告。

## 二、车主使用须知与模式切换操作建议

- **无线双模切换连接排障**：
  - 车机在「同网模式」与「车机热点模式」之间相互切换后，由于 iPhone 系统可能会缓存上一张 Wi-Fi 网络的路由配置与寻址信息，**若切换后手机未能自动连上车机，请在 iPhone 的“设置”或控制中心里将「Wi-Fi 开关关闭后再重新打开」**；
  - 若在反复多次切换后仍提示连接失败，可在 iPhone 上选择「忽略此 Wi-Fi 网络」及「忽略车机蓝牙」，重新搜索配对即可瞬间恢复连接。
