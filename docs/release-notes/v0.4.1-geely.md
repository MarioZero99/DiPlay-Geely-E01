# DiPlay Geely E01 — v0.4.1-geely

吉利星瑞 E01（ECARX E01 / MediaTek MT6735 / GKUI 19，**Android 5.1 / API 22**）的 CarPlay 车机端口。

基于 `programmerguohuajing/DiPlay-Legacy-Android` **v0.2.7**。本版没有重新核对上游。
覆盖安装即可，原来的设置和保存的热点都还在。

---

## 4.0 → 4.1 改了什么

**设置页：所有设置回到一页。** 4.0 之后设置被拆成「四个入口挨个点进去」，这一版把 13 项全部
放回设置页，无线那三步的 `1 · 2 · 3` 编号留着。车机是宽屏，卡片**两两一行**，一屏能看到的东西多了一倍。

**无线**

- 车机上根本没有能承载这条路的电台时，页面直接说**这台车机不支持**，不再只列「还差什么」。
- **热点被拒时不再顺手把车机 Wi-Fi 关掉。** 以前热点没开成，你的 Wi-Fi（和 Wi-Fi 调试）跟着一起没了，
  而且不恢复；现在只有「放掉 Wi-Fi 真有可能成功」时才放，试完还是没成就放回去。
- 一次被顶掉的连接不再留下自己的发现应答器，一个进程只有一个。
- 这条路上的失败原因以前到不了诊断报告，现在会进去。

**有线**

- USB 那头不读数据时，接收队列以前没有上限（这台车可用内存常态只有 26–33 MB）。
  现在到 1 MiB 就按对端断开处理，和收到 RST 走同一条路。
- 手机在弹「是否允许」那几秒，不再把这条通路上的写失败当成故障。

**其他**

- 进了热点设置不保存也能退出来；被拒的连接那条卡片会重算，不再记着当时的答案；
  无线模式选过之后永远留着改回去的入口。
- 比亚迪的 HUD、电池、充电输出相关内容从这个移植里去掉（E01 上没有对应硬件）。

软件版本号和上面不一样**不代表不能用**，但下面那段风险提示的实际情况**可能和这台车不同**，

> 车上通不通要你自己试。

## ⚠️ 风险提示：无线会改动车机蓝牙的底层

**这一段请看完再决定装不装。**

无线 CarPlay 用的是车机自己那套厂商蓝牙。为了把 CarPlay 需要的数据通道接上去，DiPlay 会
**改动车机正在运行的那个蓝牙底层进程**：

- **不改 `/system`。** 不动系统分区，**车机重启就自动还原**，你不需要做任何事。
- **应用里没有「撤销」按钮。** 想立刻还回去，就重启车机。
- 改动会一直持续到车机重启为止——**不是只有用无线的时候才发生**。只打开 DiPlay 什么都不做，
  它也会发生。

**风险，自己判断：**

- 车机自己的蓝牙功能（**打电话、蓝牙音乐**）和改动后的进程配合得怎么样，**没有在车上实测过**。
  原厂进程被换掉，这两件事有可能不正常。
- 出异常时的一般处理办法是**重启车机**。
- 这是**非官方改动**。吉利 / ECARX **不提供任何支持**，由此产生的问题**不在保修范围内**，
  也可能影响车机后续的官方 OTA 升级。

**不愿承担这个风险就别装。有线 CarPlay 不需要改动任何东西。**
