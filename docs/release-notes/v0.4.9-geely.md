# DiPlay Geely E01 — v0.4.9-geely

星瑞 E01 车机的 CarPlay 接收端。对应车机是 ECARX E01 / MediaTek MT6735 / GKUI 19，
系统 **Android 5.1（API 22）**。versionCode **49**，包名 `com.shihab.diplay`。

底子还是 `programmerguohuajing/DiPlay-Legacy-Android` **v0.2.7**。
签名与上一版完全一致，**直接覆盖安装即可**，之前保存的分辨率、音频缓冲、方向盘按键和 Wi-Fi 凭证均完整保留。

这一版的核心优化：**根治 MTK 音频回环（歌词重复播放与爆音）、实现无线自适应弹性抖动缓冲、车载导航即时平滑压音、以及实验性媒体卡片功能**。

---

## 一、功能优化与修复说明

针对 E01 原厂车机（联发科 MT6735, Android 5.1）在无线 CarPlay 下的网络抖动与音频驱动特性，进行了底层深度重构：

1. **MTK 音频回环与断流爆音彻底根治**：
   - 解决手机休眠或网络丢包时，MTK 驱动 DMA 循环读取未冲刷 PCM 导致的“重复播放上一截歌词”与断音爆鸣；
   - 判定断流刹车时，先对最后 15ms 真实声音执行余弦平滑淡出，随后写入 40ms 整帧静音冲刷 ALSA 环形缓冲区，最后调用 `pause()` 锁死硬件 DMA（严禁调用 `flush()`）；
   - 开声首段写入数据执行余弦淡入，避免方波冲击与启动喀哒声。

2. **无线自适应弹性抖动缓冲（Elastic Jitter Buffer）**：
   - 无线音乐冷启动/切歌时维持 47 包（约 1000ms）秒开；
   - 遇到网络饥饿/欠载刹车后，自动升级为 104 包（约 2200ms）深度抗抖动水位，从容容纳 iPhone 热点间歇性节电休眠；
   - 严格隔离有线（USB）连接、通话、Siri 与导航提示，这些流直通直写、零延迟响应。

3. **车载导航即时平滑压音（CompositeMediaGain）**：
   - 遇到高德/百度等导航提示音并发时，音乐音量即时压降至 0.2，播报结束立即平滑恢复；
   - 严密协同外部系统音频焦点，静音状态绝对不漏音。

4. **实验性媒体卡片功能（本地测试版）**：
   - 本地版本集成实验性媒体卡片与状态展示，方便在车机主控台上观察媒体状态与运行表现。
