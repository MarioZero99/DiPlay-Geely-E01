# DiPlay Geely E01 — v0.5.0-geely

星瑞 E01 车机的 CarPlay 接收端。对应车机是 ECARX E01 / MediaTek MT6735 / GKUI 19，系统 **Android 5.1（API 22）**。versionCode **50**，包名 `com.shihab.diplay`。

底子还是 `programmerguohuajing/DiPlay-Legacy-Android` **v0.2.7**。
签名与上一版完全一致，**直接覆盖安装即可**，之前保存的分辨率、音频缓冲、方向盘按键和 Wi-Fi 凭证均完整保留。

---

## 一、更新说明

### 1. 仪表音乐卡片
- 只向仪表同步歌曲的歌名与歌手（仪表不显示封面）。
- 切歌、播放状态与重连后的显示更稳定，不再串歌或来回跳。

### 2. 连接稳定性
- 无线握手超时、过早断开时会自动重试，减少第一次连接失败。
- 有线连接能更快识别重新插拔与链路故障。

### 3. 音频
- 无线音乐缓冲适当加宽，减少偶发卡顿与断音。

---

## 二、安装与升级说明

直接覆盖安装，所有个性化设置（分辨率、音频、方向盘、Wi-Fi 凭据）均完整保留。
安装使用 `DiPlay-Legacy-Geely-V050.apk`（官方正式签名包）。
