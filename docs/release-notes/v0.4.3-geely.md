# DiPlay Geely E01 — v0.4.3-geely

星瑞 E01 车机的 CarPlay 接收端。对应车机是 ECARX E01 / MediaTek MT6735 / GKUI 19，
系统 **Android 5.1（API 22）**。versionCode **43**，包名 `com.shihab.diplay`。

底子还是 `programmerguohuajing/DiPlay-Legacy-Android` **v0.2.7**，这一版没再对上游。
签名和上一版一样，**直接覆盖安装就行**，之前存的分辨率、音频缓冲、方向盘按键和 Wi-Fi 都还在。

这一版不大：**「同一 Wi-Fi」收回实验性功能，正式包回到车机热点**；另外修了连接、首次启动
和 IAP2 识别上的几处问题。

---

## 一、变化

### 同一 Wi-Fi 改为实验性功能

- **正式包只保留「车机热点」**。车机热点这条路 2026-10-19 在车上连通过，约 7.5 秒出画面。
- **「同一 Wi-Fi」只在本地的试验包（`-local`）里**。它在车上还没走通：两次尝试都停在
  网络层，车机自己的 Wi-Fi 掉线，iPhone 始终没有出现在同一张网上。
- 之前选过「同一 Wi-Fi」的，装正式包后**自动回到车机热点**，不会出现「页面写热点、
  实际却按同网去连」。
- 想继续试同网，装 `-local` 包；两个包同一个签名，可以互相覆盖，设置保留。

---

## 二、修复

### 连接

- **连接中可以取消**：连接过程中主按钮变成「取消」，不用等它自己失败。
  失败后按钮也不会一直灰着，1.2 秒后恢复。
- **首次启动不再默认无线**：没选过连接方式时，首页显示「请选择连接方式」，
  有线 / 无线并排，选哪个就连哪个。
- **有线模式不再念无线的词**：选有线时不显示无线的就绪项和热点提示，改为提示插线；
  车机没有 USB 主机时说明原因，并把有线按钮置灰。

### 识别（有线 / 无线都受影响）

- **IAP2 的 EA 档位可以切了**：以前参数 10 声明了 EA，参数 7 却没带打开它的消息，
  手机回 `0x1d03`。现在三个参数一起构造，答错的档位根本构造不出来。
- 默认仍是这台车上验证过的那套；想试另一套，改 `debug.diplay.iap2.profile` 后重连即可，
  不用重装。读不到、拼错、空值都会落回验证过的档位。

### 界面

- **设置抽屉加宽**：从固定 520dp 改成屏宽的 42%，夹在 680–800dp。
- **21 个音频通道全部可点**：改成 3 行 × 7 列等分，不再有大半格子跑到卡片外面。
- **测试音更轻**：PCM 只读一次，不再每次点击都在主线程读 384KB；退出时先停定时器再释放音轨。

## 三、升级

直接覆盖安装，设置保留。从上游 DiPlay 换过来仍需先卸载（签名不同）。

日常用 `DiPlay-Legacy-Geely-V043.apk`。`-local` 是试验包，带同一 Wi-Fi 和报告上传，
不建议日常使用。

## 四、在什么车机上做的

**吉利星瑞 E01**（ECARX E01 / MT6735 / GKUI 19 / Android 5.1 / API 22）。

| | |
|---|---|
| 车机软件版本 | **5068**（出厂那批是 5066） |
| 系统内部版本 | `SWFS11G0706H5181.00600` |

想自己看一眼：车机 **设置 → 关于智能平台 → 版本信息**。

版本号和上面不一样，不代表不能用；但下面那段风险提示落到你的车上**可能和这台不一样**，
自己判断。

## ⚠️ 无线仍会动车机蓝牙的底层

这条和 0.4.1 / 0.4.2 一样，没有变：为了接上 CarPlay 的数据通道，DiPlay 会**替换车机正在
运行的蓝牙底层进程**，而且**每次打开 DiPlay 都会替换**，不是只在用无线的时候。

- **不写 `/system`**，重启车机后原进程自己回来。
- **应用里没有「还原」按钮**；要马上恢复，重启车机。
- 车机原来的**电话、蓝牙音乐**在进程换过之后是否还正常，**这台车没有试过**。
- 这是非官方改动，不在保修范围内，也可能影响以后的官方 OTA。

不想接受这件事，就用有线。**有线不碰蓝牙。**
