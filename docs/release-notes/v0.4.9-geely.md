# DiPlay Geely E01 — v0.4.9-geely

星瑞 E01 车机的 CarPlay 接收端。对应车机是 ECARX E01 / MediaTek MT6735 / GKUI 19，系统 **Android 5.1（API 22）**。versionCode **49**，包名 `com.shihab.diplay`。

底子还是 `programmerguohuajing/DiPlay-Legacy-Android` **v0.2.7**。
签名与上一版完全一致，**直接覆盖安装即可**，之前保存的分辨率、音频缓冲、方向盘按键和 Wi-Fi 凭证均完整保留。

---

## 一、更新说明

### 1. 稳定性修复与系统兼容
- **修复退出后二次启动偶发闪退**：彻底修复在车机 Wi-Fi 已连接状态下，退出并重新进入应用时因高版本 API 字段兼容问题导致的偶发闪退。
- **内存优化与进程清理**：移除后台独立辅助进程拉起，大幅降低对 E01 车机可用内存的压力。

### 2. 星瑞仪表盘协同显示（实验性，未实车验证）
- **曲目信息同步**：支持将 CarPlay 当前播放的歌曲名称、歌手信息同步至星瑞液晶仪表屏。
- **专辑封面渲染**：支持向仪表盘推送当前播放音频的专辑封面缩略图。
- **说明**：该功能已完成底层服务与广播绑定，尚未进行实车环境完整验证，实际显示效果以车机实测为准。

### 3. 车机系统资源治理（⚠️ 重点功能与风险警告）
- **后台语音治理开关**：支持通过 Root 权限在连接 CarPlay 期间自动冻结原车语音服务（natp），释放约 100MB+ 车机运行内存，缓解车机高负荷卡顿。
- **⚠️ 重要警告（请务必知悉）**：
  1. 开启此开关后，**原车语音助手（“你好吉利”及方向盘语音按键）将完全失效**。
  2. **当前版本 CarPlay 麦克风输入与 Siri 语音尚未调通**。
  3. 因此开启该选项后，**车内将处于完全没有可用语音助手的状态**（原车语音和 Siri 均无法使用）。如日常严重依赖语音导航或语音拨打电话，**请勿开启此开关**。

### 4. 音频体验与抗抖动优化
- **MTK 音频回环与断流爆音根治**：解决网络抖动或丢包时 MTK 驱动 DMA 循环读取未冲刷 PCM 导致的重复播音与爆音；断流时平滑淡出并冲刷 ALSA 缓冲区，开声执行余弦淡入。
- **无线自适应弹性抖动缓冲（Elastic Jitter Buffer）**：冷启动维持约 1000ms 秒开，遇网络饥饿自动平滑调整水位至 2200ms 抗抖动，直通隔离通话与导航流。
- **车载导航平滑压音（CompositeMediaGain）**：外部导航播报时平滑压降音乐音量至 0.2，播报结束立即平滑恢复。

### 5. 诊断与导出优化
- 修复 U 盘日志导出时的目录读取权限问题，解决部分 U 盘插入后无法读取目录导致导出失败的情况。
- 整合诊断界面，移除重复的上传入口。
