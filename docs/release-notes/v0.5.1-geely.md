# DiPlay Geely E01 — v0.5.1-geely

星瑞 E01 车机的 CarPlay 接收端。对应车机是 ECARX E01 / MediaTek MT6735 / GKUI 19，系统 **Android 5.1（API 22）**。versionCode **51**，包名 `com.shihab.diplay`。

底子还是 `programmerguohuajing/DiPlay-Legacy-Android` **v0.2.7**。
签名与上一版完全一致，**直接覆盖安装即可**，之前保存的分辨率、音频缓冲、方向盘按键和 Wi-Fi 凭证均完整保留。

这一版是 0.5.0 之后的优化汇总：**U 盘诊断导出修好并提速、方向盘按键该还就还、仪表歌词同步更稳**。

---

## 一、更新说明

### 1. U 盘诊断日志导出
- **修复**：正确定位并写入 U 盘 FAT32 分区；跨零点日志轮转后仍能取到刚写出的归档；一次导出当前这一场的全部日志，不再只带最后一份。
- **提速**：脱敏与报告组装跳过不可能命中的匹配；报告只读当前一份日志，轮转空文件时退回当天最新归档；为组装、脱敏、写入与备份加了阶段计时。
- **体验**：地点卡选中即写入 U 盘根目录 `DiPlay`，不再走目录树浏览；只报当天，日志在车机上保留七天。

### 2. 方向盘按键
- 只有 CarPlay 在线时才占用方向盘；会话结束或退出 DiPlay 立即归还车机，不会出现 App 已退出方向盘还被占着的情况。

### 3. 仪表音乐卡片
- 歌词行同步更稳，不再在切歌与重连时错位。
- 日韩与中文媒体文本做了清洗：剥离假名注音、折叠多余空白、规范化标点，第二行按可用宽度自适应排版。
