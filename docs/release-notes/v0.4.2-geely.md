# DiPlay Geely E01 — v0.4.2-geely

星瑞 E01 车机的 CarPlay 端口。对应车机是 ECARX E01 / MediaTek MT6735 / GKUI 19，
系统 **Android 5.1（API 22）**。

底子还是 `programmerguohuajing/DiPlay-Legacy-Android` **v0.2.7**，这一版没再对上游。
签名和上一版一样，直接覆盖安装就行，之前存的设置和热点都还在。

---

## 从 0.4.1 到现在，改了什么

**无线多了一种连法：这回让车机去连你的网。**

以前就两条路——车机自己开个热点给你连，或者走 Wi-Fi Direct。这一版多了第三种：
**车机不开热点了，改成连上一张本来就有的网**。安卓手机开的热点、家里的路由器、
iPhone 的个人热点，都行，只要 iPhone 也在这张网上。

选了这个模式，**什么也不用填**。网名是 DiPlay 从车机当前连着的那张网读出来的，
密码和加密方式，是从车机自己存着的那条配置里读出来的。

有两件事得先说：

- 一块无线网卡没法同时干两件事，开了热点就连不上别人的网。所以选了它，**车机自带的热点
  会被关掉**。DiPlay 只会关它，不会替你开。
- 万一这次没连上，**热点就一直关着**。想用回热点，要么去车机设置里自己打开，要么切回
  别的模式再连一次。

**无线**

- **车机热点现在能在打开 DiPlay 的时候自己开。** 设置里新加了个开关，**默认是关着的**。
- **连不上的时候，报告能看懂了。** 以前「DiPlay 没权限看车机的网络列表」和「车机上根本
  没存过这张网」报的是同一句话——可这两件事该做的正好相反，一个是去给权限，一个是去车机
  设置里把这张网连一次。现在分得开。等网卡的过程也会一路记下来，报告里能看出它卡在哪一步。
- 这条路失败的原因，以前会被日志过滤掉，现在留得下来。

**方向盘**

- **上一首 / 下一首不再顺手把车机自己的键也抢过来。** 以前要得太多，连播放/暂停这种
  DiPlay 压根没打算管的键也一起要走了，结果车机上按它就不灵了；语音键也一样，在我们这层
  被白白吃掉一次。现在只拿驱动真正交出来的那几个。

## 在什么车机上做的

**吉利星瑞 E01**（ECARX E01 / MT6735 / GKUI 19 / Android 5.1 / API 22）。

| | |
|---|---|
| 车机软件版本 | **5068**（出厂那批是 5066） |
| 系统内部版本 | `SWFS11G0706H5181.00600` |

想自己看一眼：车机 **设置 → 关于智能平台 → 版本信息**。

版本号和上面不一样，不代表不能用；但下面那段风险提示落到你的车上**可能和这台不一样**，
自己判断。

> 这一版有的部分上过车，有的没有。上面写的是代码里改了什么；没验过的那些，
> 车上通不通得你自己试。

## ⚠️ 先说清楚：无线会动车机蓝牙的底层

**这段看完再决定装不装。**

无线 CarPlay 借的是车机自己那套厂商蓝牙。为了把 CarPlay 要的数据通道接上，
DiPlay 会**动车机正在跑的那个蓝牙底层进程**：

- **不写 `/system`。** 系统分区不动，**车机重启就自己回去了**，你不用做任何事。
- **应用里没有「撤销」按钮。** 想马上还回去，重启车机。
- 这个改动**会一直留到车机重启为止**——不是「只用无线的时候才发生」。
  你只是打开 DiPlay，什么都不做，它也会发生。

**风险，自己掂量：**

- 车机自己的蓝牙（**打电话、放蓝牙音乐**）和改过的进程搭不搭得上，**没在车上试过**。
  原厂进程被换掉了，这两件事有可能不正常。
- 真出问题，一般的办法是**重启车机**。
- 这是**非官方改动**。吉利 / ECARX **不给任何支持**，由此带来的问题**不在保修范围**，
  也可能影响车机后面的官方 OTA 升级。

**不想担这个风险，就别装。有线 CarPlay 什么都不用动。**
