# DiPlay Geely E01 — v0.4.4-geely

星瑞 E01 车机的 CarPlay 接收端。对应车机是 ECARX E01 / MediaTek MT6735 / GKUI 19，
系统 **Android 5.1（API 22）**。versionCode **44**，包名 `com.shihab.diplay`。

底子还是 `programmerguohuajing/DiPlay-Legacy-Android` **v0.2.7**，这一版没再对上游。
签名和上一版一样，**直接覆盖安装就行**，之前存的分辨率、音频缓冲、方向盘按键和 Wi-Fi 都还在。

这一版主要两件大事：**「同一 Wi-Fi」无线模式正式调通回归**，以及**触摸响应大幅提速，滑动跟手度显著提升**。

---

## 一、同一 Wi-Fi（正式上线）

上一版（0.4.3）因在实车上还在联调而暂时下架的「同一 Wi-Fi」模式，在这一版已彻底调通，正式上线！

**车机无需开热点，车机和 iPhone 同时连入同一张 Wi-Fi**（如安卓手机热点、便携 Wi-Fi 或家庭路由器），即可秒连无线 CarPlay。

- **实机调通**：彻底修复了底层把热点网关 IP 误判为手机已连入二层网络的严重缺陷，小米等安卓热点同网秒连。
- **未配密码 0 秒即时拦截**：连接加密 Wi-Fi 时，若车机 DiPlay 尚未配置密码，0 秒直接提示输入，不再盲目傻等 30 秒超时。
- **密码错误精准提示**：若车机密码输入有误导致 iPhone 无法入网，界面明确提示“检查车机 DiPlay 密码与手机入网状态”，并自动停止死循环重试，保护车机性能与日志。
- **密码输入防呆**：保存 Wi-Fi 密码时自动剔除首尾误输入的空格，并强制校验 WPA2 最低 8 位长度，避免手滑输错。

---

## 二、触摸提速与滑动跟手

针对吉利 E01 车机 MT6735 芯片性能有限、高频滑动容易积压卡顿的问题，全面重构了触摸上行链路：

- **专属触摸队列（TouchDispatchQueue）**：滑动列表或拖动地图时，自动合并密集的 `MOVE` 触摸事件，只把最新的手指位置发给手机，彻底消除触摸事件排队导致的掉帧与画质卡死。
- **毫秒级时间戳对齐**：触摸事件带上手指触屏的真实硬件时刻，苹果端计算惯性滑动更精确自然。
- **热路径零冗余开销**：去除了触摸事件频繁触发的底层无用十六进制格式化与日志打印，大幅减轻 GC 压力。
