# DiPlay Geely E01 — v0.4.7-geely

星瑞 E01 车机的 CarPlay 接收端。对应车机是 ECARX E01 / MediaTek MT6735 / GKUI 19，
系统 **Android 5.1（API 22）**。versionCode **47**，包名 `com.shihab.diplay`。

底子还是 `programmerguohuajing/DiPlay-Legacy-Android` **v0.2.7**。
签名与上一版完全一致，**直接覆盖安装即可**，之前保存的分辨率、音频缓冲、方向盘按键和 Wi-Fi 凭证均完整保留。

这一版的核心优化：**单射频状态机全面重构，车载热点与同网 Wi-Fi 自动调度，消除射频冲突与死锁**。

---

## 一、功能优化与体验改进

针对吉利星瑞 MT6735 单射频芯片（无法同时开启 Wi-Fi 客户端与车载 AP 热点）的硬件特性，对无线控制与网络切换体验进行了全面重构：

- **热点与 Wi-Fi 互斥自动调度**：
  - **车机热点模式**：系统会自动确保 Wi-Fi 彻底关闭释放射频后再开启热点；若热点未能就绪，保持释放状态，不再反复回切 Wi-Fi，彻底消除网络拉锯；
  - **同网 Wi-Fi 模式**：系统会自动确保车机热点彻底关闭后再开启 Wi-Fi，保障快速连接外部网络或手机热点；
- **消除过渡态误判与卡顿**：精确感知 Wi-Fi 开启与关闭的真实底层状态（区分过渡中与彻底关闭），杜绝在 Wi-Fi 尚未彻底释放时抢开热点导致的硬件死锁；
- **有线（USB）模式完全隔离**：选择有线连接或使用 USB 投屏时，系统完全不干扰车机 Wi-Fi 与热点；
- **简化设置体验**：移除多余的“自动开启热点”冗余设置开关，与同网 Wi-Fi 统一为全自动按需调度。

---

## 二、重要说明与使用风险告知

- **自动使用 Root 提权（仅限吉利星瑞 E01）**：
  - 本版本中 Wi-Fi 与车机热点的全自动后台切换、射频释放与静默启闭功能，**会全自动通过吉利星瑞 E01（GKUI 19 / ECARX E01）车机系统的内置通道进行 Root 提权执行，其他车机或设备不适用**；
  - **未获取 Root 权限或非 E01 车机**：受 Android 系统安全限制，应用无法自动完成 Root 提权并启闭射频硬件，用户需在车机系统自带的“设置”界面中手动开启或关闭 Wi-Fi / 热点；
  - 后台命令均内置了严格的防堆叠与超时熔断保护，绝不会因为底层无响应而阻塞车机系统流畅度。
