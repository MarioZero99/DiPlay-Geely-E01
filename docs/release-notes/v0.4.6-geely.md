# DiPlay Geely E01 — v0.4.6-geely

星瑞 E01 车机的 CarPlay 接收端。对应车机是 ECARX E01 / MediaTek MT6735 / GKUI 19，
系统 **Android 5.1（API 22）**。versionCode **46**，包名 `com.shihab.diplay`。

底子还是 `programmerguohuajing/DiPlay-Legacy-Android` **v0.2.7**，这一版未再对齐上游。
签名与上一版完全一致，**直接覆盖安装即可**，之前保存的分辨率、音频缓冲、方向盘按键和 Wi-Fi 凭证均完整保留。

这一版的核心修复：**修复正式版安装包中看不到「同一 Wi-Fi」模式入口的问题，全面恢复双模式无线连接**。

---

## 一、正式版恢复「同网 Wi-Fi」入口（车载热点与同网双模式并立）

针对用户反馈正式版（`DiPlay-Legacy-Geely-Vxxx.apk`）中看不到「同一 Wi-Fi」模式入口的问题进行了修复：

- **恢复同网无线模式**：修复了正式版中误隐藏「同一 Wi-Fi」无线模式的问题，车机与 iPhone 加入同一 Wi-Fi（iPhone 热点、安卓手机热点、家用 Wi-Fi 或随身 Wi-Fi）即可正常连接。
- **首页快捷卡片双 Tab**：首页快捷卡片正常展示「车载热点」与「同一 Wi-Fi」双模式切换 Tab，支持一键切换并快速打开 Wi-Fi 设置。
- **配置保存修复**：修复了已保存的「同一 Wi-Fi」连接模式在应用重启或读取时被重置为车载热点的问题。

---

## 二、升级说明

直接覆盖安装，设置保留。从上游 DiPlay 换过来仍需先卸载（签名不同）。

日常安装使用 `DiPlay-Legacy-Geely-V046.apk`。
